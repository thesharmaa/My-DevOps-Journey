# OSI stands for Open Systems Interconnection - a 7-layer model that shows how data moves in a network.

`Physical Layer` – 
This is the layer where raw bits are transmitted over physical mediums like cables, fiber optics, or wireless signals.
----------
`Data Link Layer – `
This is the layer where data is transferred between devices on the same network using MAC addresses and switches.
----------
`Network Layer – `
This is the layer which handles logical addressing and best path determination for datas.
----------
`Transport Layer – `
This is the layer where end-to-end delivery is provided using TCP (reliable communication) or UDP (fast communication without guarantee).
----------
`Session Layer – `
This is the layer where communication sessions between systems are established, managed, and terminated.
----------
`Presentation Layer –` 
This is the layer where data formatting, encryption, decryption, and compression are handled for the application.
----------
`Application Layer –` 
This is the layer where end-user applications like web browsers, email clients, and APIs operate.
----------

# TCP/IP Model
1. **Network Access Layer** – This is the layer where data is transferred between devices on the same network using MAC addresses and switches and raw bits are transmitted over physical mediums like cables, fiber optics, or wireless signals.

2. **Internet Layer** – This is the layer which handles logical addressing and routing of packets across networks using IP addresses and routers. It's a Network Layer of OSI Model.

3. **Transport Layer** – This is the layer where end-to-end delivery is provided using TCP (reliable communication) or UDP (fast communication without guarantee).

4. **Application Layer** – This is the layer where end-user applications like web browsers, email clients, and APIs operate, data formatting happens and sessions are managed.
