🔹 touch
Create a new empty file instantly
👉 touch file.txt

🔹 cat
View or combine file content
👉 cat file.txt

🔹 head
See the first 10 lines of a file (default)
👉 head file.txt
See the first 2 lines
👉 head -n 2 file.txt

🔹 tail
See the last 10 lines of a file
👉 tail file.txt
See the last 2 lines
👉 tail -n 2 file.txt
🔥 Bonus: tail -f logs.txt (real-time log monitoring)

🔹 echo
Print text or write into files
👉 echo "Hello" > file.txt
👉 echo "Myself Aman" >> file.txt

🔹 tee
Display output AND save it to a file at the same time
👉 echo "Hello" | tee file.txt
👉 echo "Myself Aman" | tee -a file.txt
