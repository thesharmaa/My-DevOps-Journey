## VPC and Internet Gateway

### VPC (Virtual Private Cloud)
A VPC is a **private virtual network** inside a cloud provider where you can deploy resources securely. 

**Uses:**  
- Isolated cloud network  
- Secure deployment of resources  

---

### Internet Gateway
An Internet Gateway is a **VPC component** that allows servers (EC2) or services (virtual machines, web servers, etc.) in **public subnets** to communicate with the internet, enabling both **incoming and outgoing traffic**.

**Uses:**  
- Internet access for servers  
- Public services like web apps
