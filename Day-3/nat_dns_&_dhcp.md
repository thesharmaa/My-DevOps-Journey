## NAT, DNS, and DHCP

### NAT (Network Address Translation)

NAT translates **private IP addresses** into a **public IP** for internet communication.

**Example:**
Private Network → Router → Internet


**Uses:**

- Multiple devices share one public IP
- Saves public IP addresses
- Improves network security


---

### DNS (Domain Name System)

DNS converts **domain names** into **IP addresses** so computers can locate each other.

**Example:**


google.com → 142.250.190.14


**Uses:**

- Website access
- Domain resolution
- Internet navigation


---

### DHCP (Dynamic Host Configuration Protocol)

DHCP automatically assigns **IP addresses** and network settings to devices.

**Provides:**

- IP address
- Subnet mask
- Gateway
- DNS

**Uses:**

- Automatic network configuration
- Simplifies network management
- Reduces manual configuration errors
