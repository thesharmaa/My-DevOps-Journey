# IP Address

An **IP address (Internet Protocol address)** is a unique number assigned to every device on a network so devices can communicate with each other.

### Example
`192.168.1.10`

### Types of IP Addresses

**IPv4 (32-bit)**  
Most commonly used IP address format.  
Example: `192.168.1.10`

**IPv6 (128-bit)**  
Newer version designed to support a much larger number of devices.  
Example: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`

---

### Public IP

A **Public IP address** is accessible over the internet and is assigned by an Internet Service Provider (ISP).

**Uses**
- Hosting websites
- Internet communication
- Accessing cloud services

---

### Private IP

A **Private IP address** is used within internal networks and cannot be accessed directly from the internet.


**Uses**
- Internal communication
- Office networks
- Cloud VPC networks

---

### Static IP

A **Static IP address** is a fixed IP address that does not change.

**Uses**
- Web servers
- Database servers
- Network infrastructure

---

### Dynamic IP

A **Dynamic IP address** is automatically assigned using **DHCP (Dynamic Host Configuration Protocol)** and can change over time.

**Uses**
- Home networks
- Office networks
- Temporary device connections
